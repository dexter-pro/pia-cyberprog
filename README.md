# Cybersecurity Programming Toolkit

Colección de herramientas desarrolladas en Python para practicar conceptos de programación aplicados a ciberseguridad.

El proyecto integra diferentes scripts relacionados con análisis de puertos, escaneo de red, cifrado de información y generación de reportes.

## Funcionalidades

### Escáner de red

Permite realizar tareas básicas de reconocimiento y analizar determinados servicios disponibles en un sistema.

### Análisis de puertos

Incluye funciones relacionadas con la identificación y procesamiento de puertos utilizados por servicios de red.

### Cifrado

Contiene ejercicios relacionados con el manejo y protección de información mediante técnicas de cifrado.

### Generación de reportes

El proyecto incluye una herramienta para generar documentos PDF a partir de los resultados obtenidos durante la ejecución de los scripts.

## Archivos principales

`scanner.py`
Herramienta principal de escaneo.

`Puertos.py`
Funciones relacionadas con puertos y servicios de red.

`encriptacio.py`
Funciones utilizadas para ejercicios de cifrado.

`crearpdf.py`
Generación automatizada de reportes PDF.

## Tecnologías

- Python
- Redes TCP/IP
- Scripting
- Generación de reportes
- Conceptos básicos de criptografía

## Objetivo

El proyecto fue desarrollado con fines educativos para aplicar programación Python a diferentes tareas relacionadas con seguridad informática.
